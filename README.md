# Задачи

Страница задач: фильтр по приоритету, создание задачи через модальное окно. React + TypeScript + Vite, без бэкенда, данные моковые. Из зависимостей только React.

## Запуск

```bash
npm install
npm run dev      # разработка
npm run build    # проверка типов + сборка
```

## Решения

- **Состояние задач** живёт в хуке `useTasks` на `useReducer`, компоненты про редьюсер не знают. Заменить моки на API можно, не трогая UI.
- **Фильтр** хранится в `App` и применяется через `useMemo`, отдельная копия отфильтрованного списка не нужна.
- **`TaskItem` в `memo`**, колбэки обёрнуты в `useCallback`: отметка одной задачи не перерисовывает остальные.
- **Модалка** на нативном `<dialog>`: фокус, Esc и подложка работают без библиотек.
- **Валидация**: пустое название (после `trim`) не создаёт задачу, показывается ошибка.
- `id` генерируется в хуке, а не в редьюсере, чтобы редьюсер оставался чистой функцией.
